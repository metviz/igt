# igt — Instagram Transcript CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python command-line tool, `igt <instagram-url>`, that prints a transcript of an Instagram reel/post video — the CLI counterpart of the Chrome extension in this repo.

**Architecture:** Pure-function core (URL parsing, models, formatters) plus two I/O seams — `Downloader` (yt-dlp) and `Transcriber` (faster-whisper) — composed by a small `pipeline.generate()`. All tests use fakes at the seams; real network/model runs live behind an opt-in `integration` marker. An optional `--backend api` reuses the extension's exact HTTP contract against a remote server.

**Tech Stack:** Python ≥3.10, stdlib `argparse`/`urllib`/`tempfile`, `yt-dlp`, `faster-whisper`, `pytest` + `pytest-cov`, `uv`.

**Spec:** There is no standalone spec file. The de-facto spec is `README.md` ("API Contract Used") plus the client behaviour in `content.js` (URL match `:22-27`, text building `:50-56`, request `:127-139`, response parsing `:141-158`). The server that implements `POST /api/ext/v1/transcript` ("GetTheScript") is **not in this repo**; its response schema is inferred only from what `content.js` reads.

## Global Constraints

Copied from the spec / the user's standing rules; every task inherits them.

- Video URL shape: `instagram.com` path `/(reel|p|tv)/<id>/?` (`content.js:25`) — CLI also accepts an optional `/<username>/` prefix.
- API endpoint: `POST {base}/api/ext/v1/transcript`; header `x-extension-token: <token>`; body exactly `{"url": <str>, "language": "auto", "includeFormats": ["txt"]}`.
- API response fields consumed: `title`, `platform`, `source`, `segments[].text`, `formats.txt`; error body `{"error": <str>}`.
- Extension default API base: `http://127.0.0.1:3010`.
- Transcript text = segment texts, trimmed, blanks dropped, joined with `"\n"` (`content.js:50-56`).
- **No path default resolves inside the repo.** An unset output root is a hard failure (`ConfigError`), never a silent fallback. Output root and cookies file inside the repo are rejected.
- Secrets (API token, cookies) come from env vars or a file path outside the repo — never argv, never committed.
- Immutable data (frozen dataclasses, tuples); files < 400 lines; functions < 50 lines; no `print` outside `cli.py`.
- TDD: failing test first, run it red, minimal code, run it green. ≥80 % line coverage on `igt`.
- Commits: `<type>: <description>`; body ends with the line `developed with the help of AI assistance`. **Never** add `Co-Authored-By` or `Claude-Session` trailers.
- Stage files explicitly (`git add cli/...`). Never `git add -A` — `.claude/`, `.ignore`, `.mcp.json`, `.gitignore` at the repo root are untracked and are not part of this work.
- All commands run from `cli/` unless stated.

## Review Focus

Inputs and conditions the spec implies but does not spell out; each is pinned by a test in the task named.

1. **Login-walled / private reel** (yt-dlp says "login required") → exit 4 with a message naming `--cookies`, no traceback. *(Task 4, Task 7)*
2. **Post with no video** (image carousel, `/p/` photo) → exit 4 "no video", not an empty transcript or crash. *(Task 4)*
3. **Music-only / silent video** → exit 5 "no speech detected", never an empty file with exit 0. *(Task 6, Task 7)*
4. **Hostile / messy URLs**: `?igsh=` tracking params, `instagram.com.evil.com`, `evilinstagram.com`, `/stories/…`, whitespace, upper-case scheme. (`content.js:24` uses `hostname.includes("instagram.com")`, which accepts the evil hosts.) *(Task 1)*
5. **Output-root safety**: `--out` with `IGT_OUT_ROOT` unset fails *before* any download; root or cookies path inside the repo (including via symlink) is rejected. *(Task 3, Task 7)*
6. **Cleanup and interrupt**: temp audio removed on success, download failure, transcribe failure; Ctrl-C exits 130. *(Task 6, Task 7)*
7. **Long videos**: SRT timestamps past 1 h and millisecond rounding (`0.9996 s` → `00:00:01,000`). *(Task 2)*

```python
import re
from dataclasses import dataclass
from urllib.parse import urlparse

from igt.errors import InvalidUrlError

_HOSTS = {"instagram.com", "www.instagram.com"}
_PATH = re.compile(r"^/(?:[A-Za-z0-9._]+/)?(reel|p|tv)/([A-Za-z0-9_-]+)/?$")


@dataclass(frozen=True)
class ParsedUrl:
    kind: str
    shortcode: str
    canonical: str


def parse_instagram_url(raw: str) -> ParsedUrl:
    parts = urlparse(raw.strip())
    if parts.scheme not in ("http", "https") or (parts.hostname or "") not in _HOSTS:
        raise InvalidUrlError(f"not an Instagram URL: {raw!r}")
    match = _PATH.match(parts.path)
    if not match:
        raise InvalidUrlError(f"not a reel/post/tv URL: {raw!r}")
    kind, code = match.groups()
    return ParsedUrl(kind, code, f"https://www.instagram.com/{kind}/{code}/")
```

(`urlparse().hostname` is already lower-cased and excludes port/userinfo, so `instagram.com.evil.com` fails the exact-set check.)

import json
from typing import Callable

from igt.models import Transcript


def to_txt(t: Transcript) -> str:
    return "\n".join(text for seg in t.segments if (text := seg.text.strip()))


def _ts(seconds: float) -> str:
    ms = round(max(seconds, 0) * 1000)
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02}:{m:02}:{s:02},{ms:03}"


def to_srt(t: Transcript) -> str:
    blocks: list[str] = []
    for seg in t.segments:
        text = seg.text.strip()
        if text:
            blocks.append(f"{len(blocks) + 1}\n{_ts(seg.start)} --> {_ts(seg.end)}\n{text}\n")
    return "\n".join(blocks)


def to_json(t: Transcript) -> str:
    return json.dumps(
        {
            "platform": t.platform,
            "title": t.title,
            "source": t.source,
            "language": t.language,
            "segments": [{"start": s.start, "end": s.end, "text": s.text} for s in t.segments],
            "formats": {"txt": to_txt(t)},
        },
        ensure_ascii=False,
        indent=2,
    )


FORMATS: dict[str, Callable[[Transcript], str]] = {"txt": to_txt, "srt": to_srt, "json": to_json}
```

from pathlib import Path
from typing import Mapping

from igt.errors import ConfigError

# cli/src/igt/config.py -> repo root. ponytail: only meaningful for an editable/dev install;
# for a wheel install this points into site-packages, which is harmless.
REPO_ROOT = Path(__file__).resolve().parents[3]


def outside(path: Path, forbidden: Path, what: str) -> Path:
    resolved = path.expanduser().resolve()
    if resolved == forbidden or forbidden in resolved.parents:
        raise ConfigError(f"{what} must not be inside the repository ({forbidden}): {resolved}")
    return resolved


def env_path(env: Mapping[str, str], name: str, forbidden: Path) -> Path | None:
    value = env.get(name, "").strip()
    return outside(Path(value), forbidden, name) if value else None


def require_out_root(env: Mapping[str, str], forbidden: Path) -> Path:
    root = env_path(env, "IGT_OUT_ROOT", forbidden)
    if root is None:
        raise ConfigError("IGT_OUT_ROOT is not set; export it to a directory outside the repo to use --out")
    return root
```

from dataclasses import dataclass
from pathlib import Path
from typing import Any, Callable, Protocol

from igt.errors import DownloadError


@dataclass(frozen=True)
class Downloaded:
    audio_path: Path
    title: str


class Downloader(Protocol):
    def fetch(self, url: str, dest: Path) -> Downloaded: ...


def _first_download(info: dict | None) -> Downloaded | None:
    if not info:
        return None
    if info.get("_type") == "playlist":  # carousel: take the first entry that has media
        for entry in info.get("entries") or []:
            found = _first_download(entry)
            if found:
                return found
        return None
    downloads = info.get("requested_downloads")
    if downloads:
        return Downloaded(Path(downloads[0]["filepath"]), info.get("title") or "")
    return None


def _explain(message: str) -> str:
    low = message.lower()
    if "login" in low or "log in" in low or "cookies" in low:
        return "Instagram requires login for this post. Pass --cookies FILE (Netscape format) or set IGT_COOKIES_FILE."
    if "429" in low or "rate-limit" in low or "rate limit" in low:
        return "Rate-limited by Instagram. Wait and retry."
    if "no video" in low:
        return "This post has no video to transcribe."
    return message.splitlines()[0] if message else "download failed"


class YtDlpDownloader:
    def __init__(self, cookies_file: Path | None = None, ydl_factory: Callable[[dict], Any] | None = None):
        self._cookies = cookies_file
        self._factory = ydl_factory

    def fetch(self, url: str, dest: Path) -> Downloaded:
        import yt_dlp

        opts: dict[str, Any] = {
            "format": "bestaudio/best",
            "outtmpl": str(dest / "%(id)s.%(ext)s"),
            "noplaylist": True,
            "quiet": True,
            "no_warnings": True,
            "no_color": True,
        }
        if self._cookies:
            opts["cookiefile"] = str(self._cookies)
        try:
            with (self._factory or yt_dlp.YoutubeDL)(opts) as ydl:
                info = ydl.extract_info(url, download=True)
        except yt_dlp.utils.DownloadError as exc:
            raise DownloadError(_explain(str(exc))) from exc
        found = _first_download(info)
        if found is None:
            raise DownloadError("This post has no video to transcribe.")
        return found
```

from pathlib import Path
from typing import Any, Callable, Protocol

from igt.errors import TranscribeError
from igt.models import Segment


class Transcriber(Protocol):
    def transcribe(self, audio: Path, language: str) -> tuple[tuple[Segment, ...], str]: ...


class FasterWhisperTranscriber:
    def __init__(self, model_size: str = "base", model_factory: Callable[..., Any] | None = None):
        self._size = model_size
        self._factory = model_factory
        self._model: Any = None

    def _load(self) -> Any:
        if self._model is None:
            factory = self._factory
            if factory is None:
                from faster_whisper import WhisperModel

                factory = WhisperModel
            # ponytail: int8 runs everywhere; expose --compute-type when a GPU is available.
            self._model = factory(self._size, device="auto", compute_type="int8")
        return self._model

    def transcribe(self, audio: Path, language: str) -> tuple[tuple[Segment, ...], str]:
        try:
            raw, info = self._load().transcribe(
                str(audio), language=None if language == "auto" else language, vad_filter=True
            )
            segments = tuple(Segment(s.start, s.end, s.text.strip()) for s in raw)  # generator: decode happens here
        except Exception as exc:  # noqa: BLE001 — model/decoder errors are third-party and varied
            raise TranscribeError(f"transcription failed: {exc}") from exc
        return segments, info.language
```

import tempfile
from pathlib import Path

from igt.download import Downloader
from igt.errors import NoSpeechError
from igt.models import Transcript
from igt.transcribe import Transcriber
from igt.url import parse_instagram_url


def generate(url: str, *, downloader: Downloader, transcriber: Transcriber, language: str = "auto") -> Transcript:
    parsed = parse_instagram_url(url)
    # Audio scratch lives in the system temp dir, never in the repo; always removed.
    with tempfile.TemporaryDirectory(prefix="igt-") as tmp:
        downloaded = downloader.fetch(parsed.canonical, Path(tmp))
        segments, detected = transcriber.transcribe(downloaded.audio_path, language)
    if not any(s.text.strip() for s in segments):
        raise NoSpeechError("no speech detected in this video (music-only or silent)")
    return Transcript("instagram", downloaded.title, "local-whisper", detected, segments)

```python
import argparse
import os
import sys
from pathlib import Path
from typing import Mapping, Sequence, TextIO

from igt import __version__
from igt.config import REPO_ROOT, env_path, outside, require_out_root
from igt.download import Downloader, YtDlpDownloader
from igt.errors import IgtError
from igt.formatters import FORMATS
from igt.pipeline import generate
from igt.transcribe import FasterWhisperTranscriber, Transcriber
from igt.url import parse_instagram_url


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="igt", description="Transcribe an Instagram reel/post video.")
    p.add_argument("url", help="Instagram reel/post/tv URL")
    p.add_argument("--format", choices=sorted(FORMATS), default="txt")
    p.add_argument("--language", default="auto", help="language code or 'auto' (default)")
    p.add_argument("--model", default="base", help="faster-whisper model size (default: base)")
    p.add_argument("--cookies", help="Netscape cookies file for login-walled posts (must be outside the repo)")
    p.add_argument("--out", action="store_true", help="write to $IGT_OUT_ROOT/<shortcode>.<format> instead of stdout")
    p.add_argument("--version", action="version", version=f"igt {__version__}")
    return p


def _run(
    args: argparse.Namespace,
    env: Mapping[str, str],
    downloader: Downloader | None,
    transcriber: Transcriber | None,
    stdout: TextIO,
) -> None:
    parsed = parse_instagram_url(args.url)
    cookies = outside(Path(args.cookies), REPO_ROOT, "cookies") if args.cookies else env_path(env, "IGT_COOKIES_FILE", REPO_ROOT)
    target = None
    if args.out:  # resolve (and validate) the destination before the expensive work
        target = require_out_root(env, REPO_ROOT) / f"{parsed.shortcode}.{args.format}"
    transcript = generate(
        args.url,
        downloader=downloader or YtDlpDownloader(cookies),
        transcriber=transcriber or FasterWhisperTranscriber(args.model),
        language=args.language,
    )
    rendered = FORMATS[args.format](transcript).rstrip("\n") + "\n"
    if target is None:
        stdout.write(rendered)
        return
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_text(rendered, encoding="utf-8")
    stdout.write(f"{target}\n")


def main(
    argv: Sequence[str] | None = None,
    *,
    env: Mapping[str, str] | None = None,
    downloader: Downloader | None = None,
    transcriber: Transcriber | None = None,
    stdout: TextIO | None = None,
    stderr: TextIO | None = None,
) -> int:
    args = build_parser().parse_args(argv)
    env = os.environ if env is None else env
    stdout, stderr = stdout or sys.stdout, stderr or sys.stderr
    try:
        _run(args, env, downloader, transcriber, stdout)
        return 0
    except IgtError as exc:
        stderr.write(f"error: {exc}\n")
        return exc.exit_code
    except KeyboardInterrupt:
        stderr.write("interrupted\n")
        return 130
```

import threading
from contextlib import contextmanager
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer


@contextmanager
def serve(status: int, body, capture: dict):
    class Handler(BaseHTTPRequestHandler):
        def do_POST(self):
            length = int(self.headers.get("Content-Length", 0))
            capture["path"] = self.path
            capture["token"] = self.headers.get("x-extension-token")
            capture["body"] = json.loads(self.rfile.read(length) or b"{}")
            raw = body if isinstance(body, bytes) else json.dumps(body).encode()
            self.send_response(status)
            self.send_header("Content-Type", "application/json")
            self.end_headers()
            self.wfile.write(raw)

        def log_message(self, *args):
            pass

    server = ThreadingHTTPServer(("127.0.0.1", 0), Handler)
    threading.Thread(target=server.serve_forever, daemon=True).start()
    try:
        yield f"http://127.0.0.1:{server.server_address[1]}"

```python
import json
import urllib.error
import urllib.request
from urllib.parse import urlparse

from igt.errors import ApiError, ConfigError
from igt.models import Segment, Transcript

_LOOPBACK = {"127.0.0.1", "localhost", "::1"}


def _json_dict(raw: bytes) -> dict:
    try:
        value = json.loads(raw)
    except ValueError:
        return {}
    return value if isinstance(value, dict) else {}


def _num(value) -> float:
    return float(value) if isinstance(value, (int, float)) else 0.0


def parse_payload(payload: dict) -> Transcript:
    segments = tuple(
        Segment(_num(s.get("start")), _num(s.get("end")), s["text"].strip())
        for s in payload.get("segments") or []
        if isinstance(s, dict) and isinstance(s.get("text"), str)
    )
    txt = (payload.get("formats") or {}).get("txt")
    if not segments and isinstance(txt, str) and txt.strip():  # same fallback as content.js:148-151
        segments = (Segment(0.0, 0.0, txt.strip()),)

    def text(key: str, default: str) -> str:
        v = payload.get(key)
        return v.strip() if isinstance(v, str) and v.strip() else default

    return Transcript(text("platform", "unknown"), text("title", ""), text("source", "unknown"), text("language", ""), segments)


class ApiClient:
    def __init__(self, base_url: str, token: str, timeout: float = 60.0):
        base = base_url.strip().rstrip("/")
        parts = urlparse(base)
        if parts.scheme not in ("http", "https") or not parts.hostname:
            raise ConfigError(f"invalid IGT_API_BASE_URL: {base_url!r}")
        if parts.scheme == "http" and parts.hostname not in _LOOPBACK:
            raise ConfigError("refusing to send the token over plain http to a non-loopback host; use https")
        if not token.strip():
            raise ConfigError("IGT_API_TOKEN is not set")
        self._endpoint = f"{base}/api/ext/v1/transcript"
        self._token = token.strip()
        self._timeout = timeout

    def transcribe(self, url: str, language: str = "auto") -> Transcript:
        request = urllib.request.Request(
            self._endpoint,
            data=json.dumps({"url": url, "language": language, "includeFormats": ["txt"]}).encode(),
            method="POST",
            headers={"Content-Type": "application/json", "x-extension-token": self._token},
        )
        try:
            with urllib.request.urlopen(request, timeout=self._timeout) as resp:
                payload = _json_dict(resp.read())
        except urllib.error.HTTPError as exc:  # before URLError: it is a subclass
            error = _json_dict(exc.read()).get("error")
            raise ApiError(error if isinstance(error, str) and error else f"Request failed: {exc.code}") from exc
        except (urllib.error.URLError, OSError) as exc:
            raise ApiError(f"cannot reach API at {self._endpoint}: {exc}") from exc
        return parse_payload(payload)
```

## Appendix: Review of the existing Chrome extension (not changed by this plan)

Findings, most important first; propose as a separate follow-up plan.

1. **Token in `chrome.storage.sync`** (`popup.js:42`) syncs a secret to the user's Google account; use `storage.local`.
2. **Content-script `fetch` to an arbitrary origin** (`content.js:128`): since Chrome 85 content-script requests are subject to the page's CORS, so the custom `x-extension-token` header forces a preflight that the server must satisfy for `https://www.instagram.com`. The MV3-correct design is to send the request from a background service worker (where `host_permissions` apply). There is no `background` in `manifest.json`.
3. **`host_permissions: https://*/*, http://*/*`** (`manifest.json:7`) is far broader than needed; scope it to the configured API origin (optional host permissions).
4. **Loose host check** `location.hostname.includes("instagram.com")` (`content.js:24`) matches `instagram.com.evil.com`; the `matches` pattern limits real exposure, but the check should be exact.
5. **Stale-response race** (`content.js:106-167, 236-242`): navigating reel A → B while a request is in flight lets A's response render in B's panel (`removeUI` resets `isLoading` but the pending promise still writes to the new `ui`). Tag each request with the URL/an AbortController and ignore mismatches. No fetch timeout either.
6. **Sends `location.href` with tracking params** (`?igsh=…`) to the server; canonicalise first (as `igt` does).
7. **Duplicated logic**: `DEFAULT_SETTINGS`/`normalizeBaseUrl` copied in `content.js` and `popup.js`; `.replace(/\/$/, "")` strips only one trailing slash. Redundant `setInterval` + `MutationObserver` polling for URL change (`content.js:267-276`).
8. **No tests, no lint, no schema for the server response** — the same TDD approach (Vitest + jsdom, fake `chrome.*`) would fit if the extension is kept.
